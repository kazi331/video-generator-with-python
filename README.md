# Klip promo video kit

Makes a ~30 s promo video (zoom effects, music, sound effects, AI voiceover) entirely on your own computer.
No API keys, accounts or paid services. Everything used is free/open source.

## 1. Install (once)
- Python 3.10+  (https://python.org)
- FFmpeg        (Windows: `winget install ffmpeg` | Mac: `brew install ffmpeg` | Ubuntu: `sudo apt install ffmpeg`)
- Python packages:
      pip install -r requirements.txt
- If you get an "espeak" error from the voice step, install espeak-ng
  (Ubuntu: `sudo apt install espeak-ng` | Mac: `brew install espeak-ng` | Windows: https://github.com/espeak-ng/espeak-ng/releases)

## 2. Download the voice model (once, ~350 MB)
      python download_models.py

## 3. Make the video
      python make_video.py
Result: `output/klip-promo.mp4`. Rendering takes several minutes (it is CPU-only).

## Files
- `tts.py`        voiceover text + voice choice (edit LINES, VOICE)
- `audio.py`      synthesized music, sound effects, mixing/ducking under the voice
- `render.py`     all visuals/scenes/zoom camera (edit texts, colors, logo, timings here)
- `make_video.py` runs all steps in order
- `fonts/`        Poppins (OFL license) + DejaVu Sans Mono

## Common edits
- Narration: `LINES` in tts.py (keep 6 lines, one per scene).
- Your URL on screen: search `klip.kazisharif.dev` in render.py.
- Colors: VIOLET / CYAN / PINK / GREEN near the top of render.py.
- Real logo: edit `make_logo()` in render.py (the gradient "K" square) to paste your own PNG.
- Quick preview of single frames (seconds): `python render.py test 3.8 12 20`  -> build/test_*.png
- Scene lengths follow the voiceover length automatically.
